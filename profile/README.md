## Inside HydroCAD

HydroCAD is a local Windows hydrology app with a named hydro desk, a short pond list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside a watershed you already own and holds only the pond that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra ponds wait for their own title. HydroCAD starts with a local profile and does not need a complex account system.

The hydro desk stays on a project you already keep. Untitled ponds stay off the live list.

## Quick Start with HydroCAD

1. Open the last HydroCAD session on a watershed you own, not a new empty pond list.
2. Read the hydro desk and the last handoff.
3. Finish one visible hydrograph view inside HydroCAD.
4. Write what changed, then close with a shorter pond list than you found.
5. If the desk feels crowded, drop anything that belongs to a different project.
6. Leave the hydro desk on a watershed you already keep.
7. If a pond is not yours, leave it off the live list.
